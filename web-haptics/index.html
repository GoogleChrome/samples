Background

The Web Haptics API (Chrome Platform Status) lets web applications request semantic tactile feedback via navigator.playHaptics(effect, intensity) instead of authoring raw millisecond vibration buzzes. The browser maps six interaction and outcome intents (hint, tick, align, edge, success, and error) to the active platform's native tactile vocabulary.

navigator.playHaptics() is not enabled in this browser. Interactive controls below will run in visual simulation mode. To enable hardware haptics in Chrome, turn on chrome://flags/#web-haptics-on-android (Android) or chrome://flags/#enable-experimental-web-platform-features.
