PWA Popup Blocker Test

To verify the PWA popup blocker fix:

  1. Install this page as a PWA (click the install icon in the address bar).
  2. Launch the installed PWA.
  3. Click the Trigger Blocked Popup (Ungestured - Wait 3s) button, which will try to open a popup after 3 seconds (losing user activation/gesture). Or, reload the PWA page (it attempts to open a popup on load).
  4. Verify that a blocked popup icon (a small window with a red cross) appears in the PWA title bar.
  5. Click the icon in the title bar to see the blocked popup option (e.g. allowing popups from this site).
