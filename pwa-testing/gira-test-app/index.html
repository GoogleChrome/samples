getInstalledRelatedApps()

Detect if your app is already installed on the user's device

💡 What is it?

The navigator.getInstalledRelatedApps() API can be used to check for the installation of Progressive Web Apps (PWAs), Universal Windows Platform (UWP) apps, and Android apps that are related to the web app calling this method.

⚡ Basic Usage

const installedApps = await navigator.getInstalledRelatedApps?.();
console.log(installedApps);

🔧 More on How to Set It Up

Check if your own Desktop PWA is installed (same scope)
Supported on: Android — Chrome 84+ Desktop — Chrome / Edge 140+

1. Tell your PWA about itself

Add a related_applications entry in your web app manifest:

"related_applications": [{
  "platform": "webapp",
  "url": "/manifest.json",
  "id": "https://example.com/?utm_source=home_screen"
}]

2. Check if the PWA is installed

Call navigator.getInstalledRelatedApps() from within the scope of your PWA. If called outside the scope, it returns []. 

const relatedApps = await navigator.getInstalledRelatedApps();
console.log(relatedApps);
Check if a PWA is installed (different scope/origin)
Supported on: Android only — Chrome 84+

1. Tell your PWA about your website

Add an assetlinks.json file to /.well-known/ on the PWA's domain: 

// Served from https://app.example.com/.well-known/assetlinks.json
[{
  "relation": ["delegate_permission/common.query_webapk"],
  "target": {
    "namespace": "web",
    "site": "https://www.example.com/manifest.json"
  }
}]

2. Tell your website about your PWA

{
  "related_applications": [{
    "platform": "webapp",
    "url": "https://app.example.com/manifest.json"
  }]
}
Check if an Android app is installed
Supported on: Android only — Chrome 80+

1. Tell your Android app about your website

Update your Android app to define the relationship using Digital Asset Links.

In AndroidManifest.xml, add an asset_statements entry:

<manifest>
  <application>
    <meta-data
      android:name="asset_statements"
      android:resource="@string/asset_statements" />
  </application>
</manifest>

In strings.xml:

<string name="asset_statements">
  [{
    \"relation\": [\"delegate_permission/common.handle_all_urls\"],
    \"target\": {
      \"namespace\": \"web\",
      \"site\": \"https://example.com\"
    }
  }]
</string>

2. Tell your website about your Android app in the app manifest

{
  "related_applications": [{
    "platform": "play",
    "id": "com.android.chrome"
  }]
}
Check if a Windows (UWP) app is installed
Supported on: Windows — Chrome 85+ / Edge 85+

1. Tell your Windows app about your website

Use URI Handlers. Add to Package.appxmanifest: 

<Extensions>
  <uap3:Extension Category="windows.appUriHandler">
    <uap3:AppUriHandler>
      <uap3:Host Name="example.com" />
    </uap3:AppUriHandler>
  </uap3:Extension>
</Extensions>

2. Tell your website about your Windows app

Create a windows-app-web-link file (no .json extension) in your web server root or /.well-known/: 

[{
  "packageFamilyName": "MyApp_9jmtgj1pbbz6e",
  "paths": ["*"]
}]

Add the UWP reference to the app manifest:

{
  "related_applications": [{
    "platform": "windows",
    "id": "MyApp_9jmtgj1pbbz6e!App"
  }]
}
